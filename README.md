# JavaScript-Inventory-Management-System

JavaScript exercise practicing JavaScript classes, inheritance, methods and static properties/methods. Basic inventory management system for a store. 

## Features
- Product and PerishableProduct classes
- Inheritance and method overriding
- Static discount method
- Store class with inventory management
- Full testing script
